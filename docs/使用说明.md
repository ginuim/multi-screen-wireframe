# Multi-Screen Wireframe 使用说明

**语言 / Language:** [中文](使用说明.md) | [English](user-guide.md)

面向打开原型的产品、设计、评审人员。双击交付目录里的 `index.html` 即可使用，无需安装、构建或联网。

想自己试一遍，可打开仓库里的 demo：

- 桌面端：`demo/api-client/index.html`
- 移动端：`demo/travel-app/index.html`

---

## 和传统原型工具有什么不同

传统原型工具（Axure、Figma 原型、墨刀等）维护的是界面上的**元素树**：内容、样式、位置、层级都可以在工具里直接改，改完立刻反映到画布。那是「结构化编辑界面」。

本工具不是那样。页面由 AI 生成**可运行的业务源码**（`src/screens/*.js` 等）来实现界面。你在浏览器里看到的是编译/运行后的结果，**无法从画面上的外观直接反推出源码该怎么改**——同一块区域可能对应模板、状态、循环节点或共享组件，肉眼点选改样式解决不了。

所以本工具提供的是另一条路径：

1. 在修改模式里**精确定位**要改的 DOM 节点（含面包屑选父级、多选绑定多目标）。
2. 把意见整理成带稳定选择器（id / class / `data-wf-key`）的 **Prompt**。
3. 把 Prompt 交给 AI，由 AI **改源代码**；你刷新 `index.html` 验收。

修改模式不会、也不能在浏览器里直接改源码；它的价值是把「改哪里、改什么」钉死，让 AI 改对文件。

## 1. 打开原型

1. 找到交付目录（或上面的 demo）。
2. 双击 `index.html`，用 Chrome / Edge / Safari 等现代浏览器打开。
3. 首次进入默认是**画板模式**：所有页面铺在一张画布上。

页面通过 `file://` 本地加载，不依赖服务器。

## 2. 工具栏总览

顶部工具栏从左到右大致是：

| 区域 | 功能 |
| --- | --- |
| 模式 | **画板** / **演示** |
| 交互 | **可交互** / **不可交互** |
| 缩放 | 缩小、放大、复位 |
| 演示相关 | 热区、入口页、返回（仅演示模式） |
| 右侧 | 修改、注释、展开/收起屏、导出、沉浸、全屏、帮助 |

不确定某个按钮时，把鼠标悬停上看完整说明；按 `?` 打开帮助面板。

## 3. 画板模式

**用途**：一眼看清全部页面和页面之间的流程连线。

**怎么用**

1. 点工具栏 **画板**，或按 `Ctrl+1`（macOS）/ `Alt+1`（Windows/Linux）。
2. 拖动画布：
   - **不可交互（锁住）**：直接拖拽平移，滚轮缩放；不会点到页面。
   - **可交互（未锁住）**：可点页面；按住 `Space` 再拖画布；`Ctrl+滚轮` 缩放。
3. 用左侧边栏或屏标题栏的勾选框选中若干屏，再做展开/收起或打包导出。
4. **双击**某一屏（或侧栏 / 下方索引里的对应项），直接进入演示，并从该屏开始。
5. 屏卡片上可单独 **展开** / **收起**（长页看全貌），或 **导出 PNG**。

### 左侧边栏

画板左侧是**页面列表**，用来总览、定位和批量勾选：

| 操作 | 说明 |
| --- | --- |
| **单击**某一行 | 画布定位到该屏（当前屏高亮） |
| **双击**某一行 | 进入演示，并从该屏开始 |
| 行前勾选框 | 选中/取消该屏，供展开、收起、打包导出 |
| 顶部 **全选** | 一键全选或清空勾选 |
| 收起 / 展开 | 点侧栏右上角收起；收起后左侧留一条展开按钮 |

侧栏底部有两行操作提示：不可交互时怎么平移缩放，可交互时怎么拖画布。沉浸模式下侧栏会一并隐藏。

### 下方画板索引

画布下方默认有一条可拖拽可关闭的**页面索引**（编号圆点），和左侧列表功能互补——列表看标题，索引快速跳号：

| 操作 | 说明 |
| --- | --- |
| 点某个编号 | 定位到对应屏；当前屏编号高亮 |
| **双击**某个编号 | 进入演示，并从该屏开始 |
| 悬停编号 | 显示页面标题和源码路径（`src/screens/<id>.js`） |
| 拖左侧「索引」把手 | 把整条索引挪到画布任意位置 |
| 点右侧关闭 | 关掉索引 |

关掉后可在 **帮助 → 显示画板索引** 重新打开。显示开关按项目记在本机浏览器；拖拽位置只在当前会话有效。索引属于框架控件：即使处于「不可交互」，仍可点选和拖拽，不会被交互锁挡住。

## 4. 演示模式

**用途**：按真实页面流点击跳转，给评审和走查用。

**怎么用**

1. 点 **演示**，或按 `Ctrl+2` / `Alt+2`。也可在画板上双击某屏进入。
2. 用工具栏 **入口** 下拉框选演示起点；点 **返回** 回到上一屏。
3. 在屏内点按钮、链接、Tab 等带跳转的控件前进。
4. 需要看哪些区域可点时，打开 **热区**（或 `Ctrl+H` / `Alt+H`）；再点一次关闭。
5. 标题栏可临时展开当前屏，看长页全貌。
6. **双击空白处**退出演示，回到画板。

演示只允许跳转到当前页 `links` 里声明过的页面；没有连线的跳转不会发生。

---

## 5. 交互锁

**用途**：避免拖动画布或滚轮缩放时误点到页面内容。

| 状态 | 行为 |
| --- | --- |
| **不可交互（锁住）** | 页面点不动；可直接拖拽平移、滚轮缩放 |
| **可交互（未锁住）** | 可点页面内按钮、表单、Tab 等；拖画布需按住 `Space`，缩放需按住 `Ctrl`+滚轮 |

切换：点工具栏锁按钮，或 `Ctrl+I` / `Alt+I`。

在帮助设置里可勾选 **进入演示时恢复可交互**：进演示时若处于锁住状态，会自动解锁；演示中仍可手动再锁。

---

## 6. 缩放与平移

- 工具栏：缩小、放大、**复位**（重置缩放）。
- 快捷：`Ctrl+滚轮`（可交互时）；不可交互时滚轮也可缩放。
- 按住 `Space`：临时拖动画布，松开后恢复原操作。
- Mac 触摸板：可在帮助里开启 **触摸板缩放**，并调节灵敏度。

## 7. 修改模式

**用途**：精确定位页面节点，整理改稿意见，生成可复制给 AI 的 Prompt，让 AI 去改 `src/` 源码。  
**不会直接改业务源码**；记录只存在当前浏览器会话，刷新或关闭后会丢。需要保留时先复制 Prompt。

### 为什么要这样改

界面是代码跑出来的，不是可拖拽的设计稿。点选 + Prompt 是为了把「改哪个节点」钉到稳定 DOM 选择器上，避免口头描述「左边那个按钮」导致 AI 改错位置。

### 怎么选中节点

1. 点 **修改**，或按 `Ctrl+M` / `Alt+M`。
2. 在屏内点击目标。第一次点到的往往是最内层子节点（比如一行文字、一个图标）。
3. 用面板上方的 **面包屑导航** 往上选父节点：从内层点到卡片、列表项、整块模块等。点面包屑某一级，当前选中就切到该父级。  
   常见情况：你要点「整张卡片」，却先点到了卡片里的标题——用面包屑上移到卡片根节点再加入清单。
4. **多选**（一次意见绑多个目标）：
   - 打开面板里的 **多选**，再逐个点击；或
   - 按住 `Shift` / `Command` / `Ctrl` 点击追加/移除。
   - 已选列表里可单独 **移除** 某个节点；**清空** 可去掉全部已选。
5. 选好后选修改类型、写说明，点 **加入修改清单（N 个节点）**。

同一条意见会在所有目标旁显示同一个半透明**黄色编号**；点编号可浮动查看。修改过程中仍可按住 `Space` 拖动画布。

### 修改类型与示例

| 类型 | 适用 | 示例 |
| --- | --- | --- |
| **修改建议** | 自由描述 | 「把这块改成两列布局，右侧放操作按钮」 |
| **修改文字** | 换文案 | 新文字填「提交申请」 |
| **调整顺序** | 挪位置 / 对调 | 见下方「多选调换顺序」 |
| **删除节点** | 去掉某块 | 可选补充「同步清理无用代码」 |

**多选调换顺序（推荐写法）**

1. 开启多选，依次点中要互换的两个元素（必要时用面包屑选到正确层级，例如两个列表项的根节点，而不是里面的文字）。
2. 修改类型选 **调整顺序**。
3. 说明写清楚目标，例如：「把这两个节点对调位置」或「A 移到 B 之后」。
4. 加入清单 → 复制 Prompt 交给 AI。

多选也适合「同一条意见改好几处」：例如同时选中页头和页脚的同一类文案，写一条统一修改要求。

### 生成 Prompt 并交给 AI

1. 清单下方自动生成 **最终 Prompt**（含页面 ID、DOM 选择器、源码提示）。
2. 可在文本框里继续手改；点 **重新生成** 会覆盖手改内容。
3. 点 **复制 Prompt**，粘贴给 AI Agent。
4. AI 只应改业务 `src/`，按选择器在 `src/screens/*.js` 的 template 里定位节点。
5. 改完后刷新 `index.html` 验收。

按 `Esc` 可关闭面板或退出修改模式。

## 8. 注释模式

**用途**：给页面或模块加持久说明、问题、设计决策。标记为**蓝色编号**。不承载 Todo / 评审状态。

**怎么用**

1. 点 **注释**。
2. 选择范围：
   - **页面**：整页注释，用下拉框选页面。
   - **所选模块**：先点屏内模块，再写内容。
3. 填写注释，点 **添加并保存到本机**。
4. 列表里可筛选「当前页 / 全部」，可编辑、删除。
5. 点蓝色标记可查看内容。

**本机草稿与同步**

- 注释先以操作日志保存在当前浏览器，面板会显示「待同步」数量。
- 点 **复制同步 Prompt**，交给 AI，把变更幂等合并进 `src/annotations.js`。
- 刷新后，注释随原型和 Git 一起保存。
- 浏览器存不了草稿时，面板会提示；此时立刻 **导出注释 JSON**。

**跨设备交换**

| 操作 | 说明 |
| --- | --- |
| **导出注释 JSON** | 下载 `<project-id>.wireframe-annotations.json` |
| **导入注释 JSON** | 与本机草稿合并；仅同一项目 id 可导入 |
| **清除本机草稿** | 需再次确认；不影响原型内置注释 |

JSON 是备份和跨浏览器交换方式，日常改注释不必每次导出。

## 9. 展开 / 收起页面

画板或演示里，长页面或者宽页面（比如列很多的表格会出现横向滚动条）默认可能裁切，展开后可以完整查看页面内容。

- 单屏：点该屏上的 **展开** / **收起**。
- 多屏：先勾选若干屏，再用工具栏 **展开已勾选的屏** / **收起已勾选的屏**；未勾选时对全部屏生效。

展开后便于截图、导出和通读长内容。

## 10. 导出

| 方式 | 操作 |
| --- | --- |
| 单页 PNG | 在画板某一屏上点 **导出 PNG** |
| 多页 ZIP | 勾选需要的屏（默认全选导出全部），点 **打包下载** |

导出在本地浏览器完成，不上传文件。失败时画布旁会显示错误信息。

## 11. 沉浸与全屏

| 功能 | 作用 | 快捷键 |
| --- | --- | --- |
| **沉浸** | 收起常规工具栏，页面更干净；可用精简控件 | `Ctrl+3` / `Alt+3` |
| **浏览器全屏** | 整窗进入系统全屏 | `Ctrl+Shift+F` / `Alt+Shift+F` |

沉浸模式下可展开/收起精简工具栏，仍能进帮助与设置。`Esc` 退出沉浸或关闭当前面板。

点工具栏 **帮助**，或按 `?`。

### 快捷键一览

macOS 用 `Ctrl`，Windows / Linux 用 `Alt`。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/Alt+1` | 画板模式 |
| `Ctrl/Alt+2` | 演示模式 |
| `Ctrl/Alt+I` | 可交互 / 不可交互 |
| `Ctrl/Alt+M` | 修改模式 |
| `Ctrl/Alt+3` | 沉浸模式 |
| `Ctrl/Alt+Shift+F` | 浏览器全屏 |

| `Esc` | 关闭面板或退出模式 |
| `?` | 打开/关闭帮助 |

焦点在输入框、文本域、下拉框或可编辑内容时，普通快捷键不会触发。

### 画板设置

| 设置 | 说明 |
| --- | --- |
| **界面语言** | 简体中文 / 繁体中文 / English；全局保存在本机 |

## 13. 业务源码怎么改（给继续编辑的人）

交付物是普通多文件 JavaScript，不是打包应用：

1. 只改 `src/`（页面、注释、样式、业务组件）。
2. 保存后刷新浏览器。
3. 不要改 `framework/` 来绕过页面错误。
4. 某个 screen 报错时，该屏显示错误卡，其他屏仍可继续用。

组件用法见交付目录里的 `COMPONENTS.md`；完整编辑约定见 `EDITING.md`、`AGENTS.md`。

用 AI 改稿时：优先把修改模式复制出的 Prompt，或注释的同步 Prompt 直接贴给 Agent。

## 14. 推荐操作路径

| 场景 | 建议路径 |
| --- | --- |
| 自己熟悉产品 | 画板总览（左侧列表 / 下方索引跳屏）→ 双击进演示 → 开热区走主路径 |
| 评审会议 | 演示模式 + 热区；长页先展开 |
| 收集改稿 | 修改模式：面包屑选准节点 → 多选（如对调顺序）→ 复制 Prompt → AI 改源码 → 刷新验收 |
| 沉淀说明 | 注释模式写清决策 → 复制同步 Prompt → 写入源码 |
| 对外发截图 | 展开长页 → 单页 PNG 或勾选后打包 ZIP |
| 换电脑继续批注 | 导出注释 JSON → 另一台导入 |

## 15. 常见问题

**画布拖不动 / 一拖就点到页面？**  
看交互锁：未锁住时，拖画布要按住 `Space`，缩放要 `Ctrl`+滚轮；锁住后可直接拖拽平移、滚轮缩放，且不会点到页面。

**演示里点了没跳转？**  
确认已在演示模式、交互为可交互，且该控件的目标页写在当前页的页面流里。可开热区核对可点区域。

**修改清单刷新没了？**  
正常。修改只存在会话里，也不会写进源码。需要保留时先复制 Prompt，或让 AI 改完源码后再刷新。

**为什么不能像 Figma / Axure 那样直接在画布上改？**  
本工具的界面是 AI 生成的业务代码跑出来的，不是可结构化编辑的设计稿；画面外观反推不出该改哪段源码。修改模式负责精确定位节点并生成 Prompt，由 AI 改 `src/`。

**点到的总是太小的子元素？**  
用面板上方的面包屑往上选父节点，再加入清单。

**注释刷新还在，但「待同步」还在？**  
本机草稿还没写进 `src/annotations.js`。复制同步 Prompt 给 AI 合并后再刷新。

**导入注释失败？**  
JSON 必须来自同一项目 id；版本或格式不对也会失败。

**某个屏红了，别的还能用？**  
是屏级错误隔离。修好对应 `src/screens/<id>.js` 后刷新即可。
